RAVEN supports *de novo* reconstruction from the KEGG and MetaCyc databases,
homology-based reconstruction from template models, gap-filling, simulation
through flux balance analysis, omics-data integration and network
visualization — with the **same** functionality available in both
implementations.

## Citing RAVEN

If you use RAVEN in your research, please cite:

> Wang H, Marcišauskas S, Sánchez BJ, Domenzain I, Hermansson D, Agren R,
> Nielsen J, Kerkhoven EJ (2018). **RAVEN 2.0: A versatile toolbox for metabolic
> network reconstruction and a case study on *Streptomyces coelicolor*.**
> *PLoS Computational Biology* 14(10): e1006541.
