# Protocols

Curated, worked protocols for common genome-scale metabolic modelling tasks.
Each protocol is intended to be available in **both MATLAB and Python**, with
the code shown in MATLAB/Python tabs so you can follow along in either language.

## Available

<div class="grid cards" markdown>

-   :material-flask: **[GEM reconstruction](reconstruction.md)**

    Homology-based reconstruction of a genome-scale model for the yeast
    *Hansenula polymorpha* (`hanpo-GEM`), end to end — from template models to a
    growing, methylotrophic draft model.

</div>

## Planned

These protocols, adapted from the
[Human-GEM guide](https://sysbiochalmers.github.io/Human-GEM-guide/), are being
added with MATLAB and Python variants:

- **GEM extraction** — extracting context-specific models, based on
  <https://sysbiochalmers.github.io/Human-GEM-guide/gem_extraction/>.
- **GEM comparison** — comparing models, based on
  <https://sysbiochalmers.github.io/Human-GEM-guide/gem_comparison/>.
